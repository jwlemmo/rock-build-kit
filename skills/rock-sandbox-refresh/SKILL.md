# Refresh a sandbox
Read RUNBOOK.md. Discover the actual hosting and backup topology. A refresh replaces sandbox data; inventory and preserve sandbox-only work, obtain the authorized restore scope, then use the hosting provider's restore procedure. Isolate outbound integrations before allowing the restored application to start. There is no universal safe SQL sanitizer or resource name.
