# Optional operations

Core building needs Rock REST access. Hosting/server administration needs separate authorization and credentials. The portable procedures below replace host-specific runbooks; none point to the source church's cloud account.

- `rock-change-management/`: local bundles, review and promotion log
- `rock-plugin-deploy/`: plugin build/package and deployment planning
- `rock-sandbox-refresh/`: sandbox refresh and isolation procedure
- `rock-test/`: acceptance testing procedure
